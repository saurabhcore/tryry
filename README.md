# TechWorld — Professional E-commerce Frontend

A responsive, presentation-ready electronics storefront made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and interface
- `style.css` — responsive design and component styling
- `script.js` — product rendering, search, filters, sorting, wishlist, cart and simulated checkout
- `assets/` — locally bundled product images (WebP)

## Run locally
1. Extract the project folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No build tools, frameworks or backend setup are required for this frontend demo.

## GitHub upload
Upload the entire contents of this folder to the repository root, including the `assets` folder. Keep `index.html`, `style.css`, `script.js` and `assets/` together so product images load correctly. GitHub Pages can serve this static frontend.

## Demo limitations
- Product listings and prices are sample presentation data.
- Cart and wishlist work in the current browser session only.
- Checkout is simulated; it does not collect payment details or process real payments.
- Login, tracking and help are visual demo interactions.
- Product photos are illustrative product imagery, not official brand-supplied images.
