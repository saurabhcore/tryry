# TechWorld Professional Storefront

## Run locally
Open `index.html` in your browser or use VS Code Live Server.

## Files
- `index.html` — homepage structure and embedded hero/category images
- `style.css` — responsive styling
- `script.js` — product grid, search, filters, wishlist, cart and demo checkout; product images are embedded as data URLs

No separate assets folder is required. Demo checkout only; no real payments.
